- **429:** 구글이 막으면 예시 데이터로 바뀌고 "예시 데이터 · 실제 수치 아님"으로 표시됩니다. 요약 문장에서 빠지고, 캐시는 5초만 유지해 곧 다시 조회합니다. 실제로 이번 점검 중 연속 조회로 429를 받았고, 1~2분 뒤 풀렸습니다.
- **10분 캐시:** 성공한 조회는 600초 캐시합니다 (테스트로 확인).
- **네이버:** 키가 없어 실제 조회를 못 했습니다. 키 없이 조회하면 카드에 "예시 데이터", 차트에 점선과 "(예시)"가 표시됩니다.

## 3. 정밀 분석 스튜디오

- **구글:** 3개월·KR·웹, 12개월·KR·유튜브, 7일·US·쇼핑(시간 단위 168개), 5년·전세계·뉴스, 12개월·서울/경기 모두 실제 데이터로 응답했습니다.
- **네이버 (수정함):**
  - 기본값이 "1년·월간·어제까지"라서 마지막 달이 11/1~11/23의 반쪽 달이었습니다. 직전 구간 대비 변화율이 거의 항상 하락으로 나옵니다. 통합 화면에서 고친 문제와 같은 종류입니다.
  - 수정: 통합 화면과 같은 규칙으로 기간을 주·월 단위로 넓히고, 끝나지 않은 마지막 구간을 뺍니다. 기본 조회는 이제 2025-11-01 ~ 2026-10-31로 나옵니다. 화면의 "기간:" 줄에 실제 적용 기간이 표시됩니다.
  - 예시 데이터가 30일 간격으로 날짜를 만들어 12월·3월이 두 번 나오고 2월이 빠졌습니다. 달마다 하나씩 나오게 고쳤습니다.
  - 그룹 5개, 기기·성별·연령 필터는 요청 본문에 들어가는 것을 테스트로 확인했습니다. 네이버 서버에서 실제로 필터가 적용되는지는 키가 없어 확인하지 못했습니다.

## 4. 브라우저 (1440×900, 390×844, 라이트·다크)

- **라이트모드 모달:** 5개 모두 흰 배경입니다 (`rgb(255,255,255)`). ACV의 "검은 모달" 문제는 없습니다. 다크 토큰(`tailwind.config.js`)은 body 1곳에서만 쓰이고 라이트모드에서 `index.css`가 덮어씁니다.
- **Pretendard:** jsDelivr에서 실제로 불러옵니다 (`document.fonts.check('16px Pretendard')` = true). CSP도 jsDelivr와 Google Fonts를 허용합니다.
- **콘솔 오류:** 0건. 가로 넘침 없음.
- **빈 상태·로딩 상태:** 첫 화면은 자동 조회 없이 안내 문구, 조회 중에는 로딩 표시.
- **Esc 닫기:** 사용 가이드·건의·후원·스위트 메뉴는 닫힘. API 연동 모달은 안 닫힘 → 수정.
- **모바일 작은 문제 (출시 후):** "구글 트렌드" 카드 제목이 두 줄로 끊기고, 네이버 카드의 "예시 데이터 · 실제 수치 아님"이 잘립니다.
- **테마 깜박임 (수정):** 저장된 선택이 없고 시스템이 라이트면 `theme-init.js`는 라이트로 그리고 React는 다크로 바꿔 깜박였습니다. 둘 다 "저장된 선택, 없으면 다크"로 맞췄습니다.

## 5. 배포 설정

- `vercel.json`: CSP가 폰트(Google Fonts, jsDelivr)와 같은 출처 API(`connect-src 'self'`)를 허용합니다. `/api/*`는 `no-store`, `/assets/*`는 1년 캐시.
- 함수 크기: Python 의존성 설치 크기 128MB (pandas 45MB, numpy 53MB). Vercel 한도 250MB 안입니다.
- 시간 제한 30초: 보통 구글 조회는 2~4초입니다. 구글이 응답하지 않으면 요청마다 최대 10초씩 걸려 30초를 넘을 수 있습니다. 넘으면 화면에 "데이터 서버에 연결하지 못했습니다"가 뜹니다.
- 환경변수: Vercel 프로젝트에 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`이 있어야 네이버가 실제 데이터가 됩니다. CORS는 같은 출처라 `ALLOWED_ORIGINS` 설정이 필요 없습니다.
- `omni-trend-tracker.vercel.app`: `DEPLOYMENT_NOT_FOUND` (아직 배포 전).
- **확인 못 함:** Vercel 서버 IP에서 구글 트렌드가 429 없이 응답하는지는 배포 후에만 알 수 있습니다. 공유 IP라 로컬보다 자주 막힐 수 있습니다.

## 7. 문서와 실제

- 사용 안내가 "4대 플랫폼"이라고 했습니다 → "네이버·구글 두 채널"로 수정. 구글 설명의 "글로벌 관심도"를 실제(통합 화면은 KR, 스튜디오에서 지역 선택)에 맞게 수정.

- ACV 저장소: `OTT_URL` 기본값이 GitHub Pages 주소이고 OTT가 "준비 중"입니다. Vercel 배포가 응답하는 것을 확인한 뒤 고칩니다.
